# 关于灰质集群前沿实践性项目的阶段性报告

::: info 文件信息
报告单位：华川科学研究所灰质研究科      
报告人：李恒        
文件权限：保密
:::

经过与前时代资料交叉比对，我们发现，灰质及其合成造物在其无需外力变换形态、生长、消解的状态时受到特殊物质的控制，这与一直以来的灰质自消解理论冲突。在灰质造物如此融入社会的今天，我们需要警惕。

另外，我们在研究灰质核的时候发现，一种黑色物质隐藏在核的内部，这种物质在核的任何形态、温度和结构中都能保持稳定，不受到外界影响，经过灰质研究科慎重考量，在与国际组织协商后，将这种物质命名为 CPA 。使用特殊手段从核中剥离 CPA 后，核失去功能核活性，目前并不清楚 CPA 是否是使灰质发生功能的主要元素。
